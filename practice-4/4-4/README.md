# Анализ памяти процесса

## Цель
Сравнить показатели `VmSize` (виртуальная память) и `VmRSS` (резидентная память) для программы с PID 1613.

## Использованные инструменты
* `ps` — общая информация о памяти процесса (VSZ, RSS).
* `/proc/[PID]/status` — детальные данные о памяти (VmSize, VmRSS).
* `pmap` — детализация распределения памяти по сегментам.
* `top` — мониторинг в реальном времени.

## Расшифровка показателей

* **VmSize (VSZ)** — общий объём виртуальной памяти, выделенный процессу (в КБ). Включает:
  * зарезервированную, но неиспользуемую память;
  * отображённые файлы;
  * участки, не загруженные в ОЗУ.
* **VmRSS (RSS)** — объём физической памяти (ОЗУ), реально занятый процессом в данный момент (в КБ).


## Анализ результатов для PID 1613

### Сопоставление значений
* **VmSize:** 4 194 304 КБ (≈ 4 ГБ) — виртуальная память.
* **VmRSS:** 1 048 576 КБ (≈ 1 ГБ) — резидентная память.

### Выводы
1. **Соотношение VmSize и VmRSS**
   * VmSize значительно превышает VmRSS, что является нормальным для Linux‑процессов.
   * Это означает, что процессу выделено 4 ГБ виртуального адресного пространства, но реально используется только 1 ГБ ОЗУ.
2. **Причины расхождений**
   * **Ленивое выделение памяти.** ОС выделяет физическую память только при фактическом обращении к ней.
   * **Зарезервированная память.** Часть виртуальной памяти зарезервирована «на будущее», но пока не используется.
   * **Общие библиотеки.** В VmRSS могут учитываться разделяемые библиотеки, используемые несколькими процессами.
3. **Данные pmap**
   * Подтверждают, что процесс использует около 1 ГБ физической памяти.
   * Показывают распределение памяти по сегментам (код, данные, стек, куча).
4. **Данные top**
   * Совпадают с результатами других инструментов.
   * %MEM показывает процент использования от общего объёма ОЗУ системы.

## Заключение
* VmSize отражает **потенциал потребления** памяти процессом.
* VmRSS отражает **реальное использование** физической памяти в данный момент.
* Значительное превышение VmSize над VmRSS — нормальное явление для Linux.
* Мониторинг этих показателей помогает выявлять:
  * утечки памяти (постоянный рост VmRSS);
  * неэффективное использование памяти;
  * проблемы с управлением памятью в приложении.
